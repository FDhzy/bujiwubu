# 积水识别 V3 · 实验候选
未替换 Windows 演示版现用模型；不可据此判断道路安全。

用原 Keras H5 的浅层、中层和全图特征，额外拟合轻量分割层；底层权重不变。拟合用 110 张积水和 12 张未见积水的场景图；另外用 20 张积水和 4 张未见积水的场景图选阈值。下表为留出测试，不参与本轮拟合和阈值选择。

| 指标 | 原版 | V3 |
|---|---:|---:|
| 干地有误报 | 18/18 | 2/18 |
| 干地平均误报面积占比 | 47.2% | 1.8% |
| 同批 40 张积水像素召回 | 74.2% | 67.0% |
| 同批 40 张积水平均 IoU | 41.0% | 36.6% |
| 另 30 张积水平均 IoU | 56.3% | 53.2% |
| 两批中预测与积水标注完全不重叠 | 0/70 | 8/70 |

18 张干地图仅是人工目视未见积水的场景样本，不代表真实误报率。底层模型是否见过同源图片未核实。漏检增加，故不启用本候选。下一步优先诊断漏检，而不是继续提高阈值。

- 权重：`water-v3-head.json`（仅新分割层，内含底层模型 SHA-256）；不包含原 H5。
- 完整指标：`water-v3-results.json`。
- 复跑：在本目录运行 `python fit_water_v3.py <原项目目录> <含 training_checkpoints/water_model_best.h5 的目录>`，使用原本地训练数据及 TensorFlow、NumPy、OpenCV、SciPy。原始照片和日志没有上传。
