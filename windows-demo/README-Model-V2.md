# 不积洼步：Windows 模型实验（2026-11-23）

## 鞋型：只给照片建议

在本地用旧 TFLite 的三种照片视图（整图、中心裁切、水平翻转）训练了一个轻量的分类校准层。没有重训底层网络。样本按文件顺序分成互不重叠的区段，去掉完全相同的文件：225 张拟合、120 张选拒答阈值、180 张留出（每类 60 张）。原模型是否见过同源原图不明；是商品图，不代表随手拍和实际穿着。凉鞋、低帮鞋没有通过建议门槛，短靴和高筒靴没有独立标注；实验入口只可能建议“靴类”，不写入鞋型配置。

- 留出集强制分类：旧归一化路径 62/180；整图 RGB/255 104/180；新校准层 126/180。
- 有拒答时：建议 67/180，正确 55 张，错误 12 张；113 张转手选。建议的 82.1% 正确率不是整体准确率，不代表实际场景可用。
- 本地模型文件：training_checkpoints/shoe_model.tflite。其 SHA-256 必须与 shoe-params.json 一致。将它放在此目录下的 training_checkpoints 中，用已安装 TensorFlow、NumPy、OpenCV 与 Tkinter 的 Python 运行 shoe_photo_demo.py 或 Windows 批处理。不要把照片用于判断安全涉水深度。

## 积水：未采用本轮校准

H5 基线与新像素校准在相同的 40 张积水图、18 张目视未见积水的场景图上复测。负样本少，只适合诊断，不代表夜间、各种反光地面或实际摄像头的表现。

| 指标 | H5 基线 | 新候选 |
|---|---:|---:|
| 正样本平均 IoU | 41.0% | 39.8% |
| 像素召回率 | 74.2% | 60.3% |
| 正样本像素精确率 | 20.7% | 25.2% |
| 与真实积水无重叠 | 0/40 | 1/40 |
| 干场景出现误报 | 18/18 | 18/18 |
| 干场景平均误报面积 | 47.2% | 33.6% |

虽然圈得小了，但更多水没有被识别，而且场景级误报没降，因此主演示继续使用现有 H5，不加载本轮积水系数。不要用于导航和安全决策。这个目录有校准参数、代码和汇总指标，没有用户照片、原始标签、日志或模型二进制。复现时先在本目录运行 collect_shoe_eval.py ORIGINAL_ROOT THIS_DIRECTORY，再运行 fit_shoe_v2.py；积水脚本是 eval_water_v2.py ORIGINAL_ROOT，依赖本地数据和 H5 文件。
